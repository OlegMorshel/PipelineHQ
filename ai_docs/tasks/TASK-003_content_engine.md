# TASK-003: Задачи — Content Draft Engine

## Связанные User Stories
- US-003.1 — US-003.6

---

## Backend задачи

### TASK-003-B1: Модель данных контента
- Создать модель `ContentDraft`:
  - `user_id: FK`
  - `angle: enum (pain, case, belief, objection)`
  - `template_id: FK → ContentTemplate (nullable)`
  - `generated_text: text` — оригинальный сгенерированный текст
  - `edited_text: text (nullable)` — отредактированный пользователем текст
  - `final_text: text` — итоговый текст (edited или generated)
  - `status: enum (draft, published, skipped)`
  - `published_at: timestamp (nullable)`
  - `character_count: integer`
  - `created_at: timestamp`
- Создать модель `ContentTemplate`:
  - `angle: enum (pain, case, belief, objection)`
  - `name: string` — название шаблона
  - `description: text` — описание подхода
  - `prompt_template: text` — шаблон промпта для генерации
  - `example: text` — пример готового поста
  - `is_active: boolean`
- Seed данные: 3–5 шаблонов для каждого угла (итого 12–20 шаблонов)
- Миграции БД
- **Приоритет:** 🔴 Critical
- **Оценка:** 3h
- **User Story:** US-003.1, US-003.5

---

### TASK-003-B2: Сервис генерации черновиков
- Сервис `DraftGenerator`:
  - На вход: `{ user_profile, angle, template_id (optional) }`
  - На выход: `{ text, angle, character_count }`
  - Логика:
    1. Берёт шаблон промпта (или дефолтный для угла)
    2. Подставляет данные пользователя: нишу, оффер, ЦА, CTA
    3. Генерирует текст через LLM
    4. Проверяет лимит символов Threads (500)
    5. Добавляет CTA в конце
  - Формат: оптимизирован для Threads (короткий, цепляющий, с хуком)
- **Приоритет:** 🔴 Critical
- **Оценка:** 5h
- **User Story:** US-003.2

---

### TASK-003-B3: Сервис рекомендации угла
- Сервис `AngleRecommender`:
  - Анализирует историю постов пользователя
  - Ротация: pain → case → belief → objection
  - Если есть данные аналитики → учитывает engagement по углам
  - Возвращает: `{ recommended_angle, reason }`
- **Приоритет:** 🟡 High
- **Оценка:** 3h
- **User Story:** US-003.6

---

### TASK-003-B4: API — Content Draft endpoints
- `GET /api/drafts` — список всех черновиков
  - Фильтры: status, angle, date range
  - Пагинация
- `GET /api/drafts/:id` — конкретный черновик
- `POST /api/drafts/generate` — генерация нового черновика
  - Принимает: `{ angle, template_id (optional) }`
  - Возвращает: `{ draft }`
- `PUT /api/drafts/:id` — обновление (редактирование текста)
- `PUT /api/drafts/:id/publish` — отметка как "опубликовано"
- `PUT /api/drafts/:id/skip` — отметка как "пропущено"
- `GET /api/templates` — список шаблонов
  - Группировка по углам
- `GET /api/drafts/recommend-angle` — рекомендация угла на сегодня
- **Приоритет:** 🔴 Critical
- **Оценка:** 4h
- **User Story:** US-003.1 — US-003.6

---

### TASK-003-B5: Seed данных — шаблоны контента для Threads
- Создать 12–20 шаблонов:
  - **Pain (3–5):**
    - "Боль и решение"
    - "Ошибка, которую все делают"
    - "Почему [метод] не работает"
  - **Case (3–5):**
    - "Было → Стало"
    - "Что я сделал за [период]"
    - "Реальный результат клиента"
  - **Belief (3–5):**
    - "Непопулярное мнение"
    - "Почему я верю в [подход]"
    - "3 принципа, которые изменили [область]"
  - **Objection (3–5):**
    - "Но у меня нет [ресурса]..."
    - "Это не работает в моей нише?"
    - "Почему это не дорого / не сложно"
- Каждый шаблон: название, описание, промпт, пример
- Примеры адаптированы под формат Threads
- **Приоритет:** 🟡 High
- **Оценка:** 4h
- **User Story:** US-003.1

## Frontend задачи

- **Оценка:** 5h
- **User Story:** US-003.1

---

### TASK-003-F2: UI — Редактор черновика
- Текстовый editor (textarea / rich text lite)
- Счётчик символов: X / 500
- Подсветка при превышении лимита (красный)
- Метка угла (badge)

- **Оценка:** 4h
- **User Story:** US-003.3, US-003.4

---

### TASK-003-F3: UI — История черновиков

  - Угол (badge)
  - Статус
  - Дата

- Возможность "переиспользовать" старый черновик
- **Приоритет:** 🟢 Medium
- **Оценка:** 3h
- **User Story:** US-003.5
