# PipelineHQ — Скоуп MVP (Этап 1)

## Цель этапа

Доказать, что система реально:
- Структурирует действия пользователя
- Увеличивает вовлечённость аудитории в Threads
- Генерирует первые диалоги
- Приводит к заявкам

**Не автоматизация. Не красота. Результат.**

## Что входит в MVP

### 0. Регистрация и Авторизация
- Вход через Threads (Meta OAuth) — основной метод
- Вход через Gmail (Google OAuth) — альтернативный метод
- Привязка Threads к Gmail-аккаунту
- Управление сессиями (Better Auth)
- Защита роутов (middleware)

### 1. Smart Onboarding (Стратегия за 15 минут)
- Подключение профиля Threads
- Автоанализ контента → автозаполнение полей (ниша, оффер, чек, ЦА, CTA)
- Редактирование и подтверждение пользователем
- Генерация стратегии

### 2. Daily Growth Plan (Ядро)
- Ежедневный план из 3 действий:
  - 📝 Публикация (готовый черновик)
  - 💬 Engagement (5 релевантных обсуждений в Threads)
  - 🎯 Conversion action (1 прямое действие к сделке)
- Отметки выполнения
- Streak / история

### 3. Content Draft Engine
- Шаблоны углов: pain / case / belief / objection
- Генерация черновиков на основе оффера и ниши пользователя
- Редактирование черновиков в интерфейсе
- Копирование для публикации в Threads

### 4. Basic Analytics
- Подписчики до / после поста
- Профиль-клики
- Комментарии
- Отметка: "Привёл ли пост диалог?"

### 5. Lead Tracker Lite
- Таблица лидов: Имя, Откуда пришёл, Какой пост, Статус
- Статусы: new → talking → call → won / lost
- Связь поста с лидом

## Что НЕ входит в MVP

| Функционал | Почему не сейчас |
|------------|-----------------|
| Автопостинг в Threads | Фокус на осознанном действии пользователя |
| Мультиплатформенность (LinkedIn, X, IG) | Только Threads в MVP |
| AI-ассистент / чат-бот | Overcomplexity для первой версии |
| Интеграция с CRM | Lead Tracker Lite достаточно |
| Командный режим | Только solo-пользователь |
| Платёжная система | Ручной онбординг платящих через Stripe link |
| Мобильное приложение | Web-first, responsive |
| A/B тестирование контента | После валидации MVP |
| Расширенная аналитика (ROI, LTV) | После 50+ пользователей |
| Scheduled posting | Не в скоупе MVP |

## Ограничения MVP

- **Threads API** — ограниченный доступ к данным. Некоторая аналитика может быть ручной (пользователь вводит цифры сам).
- **Автозаполнение** — зависит от публичности профиля и количества контента. Если данных мало — fallback на ручной ввод.
- **Engagement suggestions** — на MVP могут быть на основе хештегов/ниши, без real-time парсинга Threads.

## Технические ограничения

- Threads API (Meta) — необходимо получить доступ через Meta for Developers
- Rate limits на API запросы
- Публичные данные профиля vs. авторизованный доступ
