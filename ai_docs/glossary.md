# PipelineHQ — Глоссарий терминов

## Бизнес-термины

| Термин | Описание |
|--------|----------|
| **Pipeline** | Воронка: путь от контента до сделки (пост → диалог → заявка → оплата) |
| **CTA (Call to Action)** | Целевое действие, к которому ведёт контент (написать в DM, записаться на созвон, перейти по ссылке) |
| **Оффер** | Конкретное предложение пользователя его аудитории (услуга, продукт, консультация) |
| **Ниша** | Тематическая область экспертизы пользователя (маркетинг, фитнес, финансы и т.д.) |
| **ЦА (Целевая аудитория)** | Идеальный клиент пользователя — кому адресован контент |
| **Средний чек** | Средняя стоимость сделки/услуги пользователя |
| **Лид** | Потенциальный клиент, который проявил интерес (написал, ответил, перешёл) |
| **Conversion Action** | Прямое действие, направленное на превращение подписчика в лида (DM, предложение созвона) |
| **Engagement** | Взаимодействие с аудиторией: комментарии, ответы в обсуждениях, реакции |

## Контент-термины

| Термин | Описание |
|--------|----------|
| **Угол (Angle)** | Подход к написанию поста: pain, case, belief, objection |
| **Pain** | Пост, раскрывающий боль целевой аудитории |
| **Case** | Пост с кейсом/историей успеха |
| **Belief** | Пост, формирующий убеждение (почему это работает) |
| **Objection** | Пост, снимающий возражение (почему это не страшно/сложно) |
| **Черновик (Draft)** | Предгенерированный текст поста, который пользователь редактирует перед публикацией |
| **Streak** | Серия дней подряд, когда пользователь выполнял дневной план |

## Платформа

| Термин | Описание |
|--------|----------|
| **Threads** | Текстовая социальная сеть от Meta, основная платформа PipelineHQ в MVP |
| **Threads API** | API от Meta для доступа к данным профиля и публикаций в Threads |
| **Bio** | Описание профиля пользователя в Threads |
| **Профиль-клики** | Переходы на профиль пользователя после просмотра поста |

## Технические термины

| Термин | Описание |
|--------|----------|
| **Smart Onboarding** | Онбординг с автозаполнением полей на основе анализа контента из Threads |
| **Content Analyzer** | Сервис анализа контента пользователя для извлечения ниши, оффера, ЦА |
| **Profile Fetcher** | Сервис получения данных профиля и постов из Threads |
| **Daily Growth Plan** | Ежедневный план из 3 действий: публикация, engagement, conversion |
| **Lead Tracker** | Модуль трекинга лидов от поста до сделки |
| **Confidence Score** | Уровень уверенности системы в автозаполненном значении поля |

## Статусы лидов

| Статус | Описание |
|--------|----------|
| **new** | Новый лид — проявил интерес |
| **talking** | В диалоге — идёт общение |
| **call** | Назначен/состоялся созвон |
| **won** | Сделка закрыта — клиент оплатил |
| **lost** | Сделка не состоялась |
