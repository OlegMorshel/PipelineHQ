# US-002: Daily Growth Plan (Ядро системы)

## Описание модуля

Каждый день пользователь видит персонализированный план из 3 типов действий в Threads:
1. **Публикация** — готовый черновик для Threads
2. **Engagement** — комментарии в 5 релевантных обсуждениях в Threads
3. **Conversion action** — 1 прямое действие к сделке

Решает главную боль: _"Не знаю, что делать сегодня"_ → конкретные шаги.

---

## User Stories

### US-002.1 — Просмотр дневного плана

**Как** пользователь,  
**я хочу** каждый день видеть конкретный план действий в Threads,  
**чтобы** не думать "что делать" и просто выполнять шаги.

**Acceptance Criteria:**
- [ ] Dashboard показывает 3 блока: **Publish / Engage / Convert**
- [ ] Каждый блок содержит конкретное действие с описанием
- [ ] Чекбоксы для отметки выполнения
- [ ] План обновляется каждый день в 00:00 по часовому поясу пользователя
- [ ] Если вчерашний план не выполнен — видно, но не блокирует новый

---

### US-002.2 — Черновик поста на сегодня

**Как** пользователь,  
**я хочу** видеть готовый черновик для публикации в Threads,  
**чтобы** мне оставалось только отредактировать и запостить.

**Acceptance Criteria:**
- [ ] Черновик генерируется на основе стратегии из onboarding
- [ ] Используется один из углов: pain / case / belief / objection
- [ ] Учитывается лимит символов Threads (500 символов)
- [ ] Можно редактировать прямо в интерфейсе
- [ ] Кнопка "📋 Скопировать" для вставки в Threads
- [ ] Отметка "✅ Опубликовано" после публикации

---

### US-002.3 — Список обсуждений для engagement

**Как** пользователь,  
**я хочу** получить 5 релевантных обсуждений/постов в Threads для комментирования,  
**чтобы** увеличивать видимость среди целевой аудитории.

**Acceptance Criteria:**
- [ ] Список из 5 тем/хештегов/авторов в нише пользователя
- [ ] Подсказка: что написать в комментарии (шаблон)
- [ ] Ссылки на обсуждения в Threads (если доступно через API)
- [ ] Отметка "Выполнено" для каждого из 5 пунктов
- [ ] Если API не даёт рекомендации → рекомендации по хештегам и авторам

---

### US-002.4 — Conversion action на день

**Как** пользователь,  
**я хочу** получить 1 конкретное conversion-действие на день,  
**чтобы** двигать воронку к реальным заявкам.

**Acceptance Criteria:**
- [ ] Действие зависит от CTA пользователя:
  - DM: "Напиши [тип аудитории] сообщение: [шаблон]"
  - Call: "Предложи созвон тому, кто комментировал: [шаблон]"
  - Link: "Добавь ссылку [X] в ответ на комментарий [Y]"
- [ ] Конкретная формулировка действия
- [ ] Отметка "Выполнено" + результат:
  - Ответил / Нет ответа / Заявка / Отказ
- [ ] При "Заявка" → предложение добавить лид в Lead Tracker

---

### US-002.5 — Streak и история выполнения

**Как** пользователь,  
**я хочу** видеть историю своих дней (streak),  
**чтобы** чувствовать прогресс и не бросать.

**Acceptance Criteria:**
- [ ] Streak-индикатор: "🔥 5 дней подряд"
- [ ] Календарь выполнения (зелёный/жёлтый/красный день)
- [ ] Процент выполнения за неделю / месяц
- [ ] Мотивационное сообщение при streak (3, 7, 14, 30 дней)

---

### US-002.6 — Пропуск и перегенерация

**Как** пользователь,  
**я хочу** иметь возможность пропустить задачу или получить новую,  
**чтобы** план был гибким и я не застревал.

**Acceptance Criteria:**
- [ ] Кнопка "🔄 Другой черновик" для публикации
- [ ] Кнопка "⏭ Пропустить" для любого действия
- [ ] Пропущенное действие не засчитывается как выполненное
- [ ] Перегенерация черновика — не больше 3 раз в день
