# US-004: Basic Analytics (Аналитика, привязанная к результатам)

## Описание модуля

Аналитика в PipelineHQ — **не про лайки**, а про бизнес-результаты:
- Какой пост привёл диалог?
- Растёт ли аудитория?
- Что работает, а что нет?

Минимум метрик, максимум смысла.

---

## User Stories

### US-004.1 — Обзор метрик по посту

**Как** пользователь,  
**я хочу** видеть ключевые метрики по каждому опубликованному посту в Threads,  
**чтобы** понимать, что работает.

**Acceptance Criteria:**
- [ ] Для каждого поста отображается:
  - Подписчики до / после поста (дельта)
  - Количество комментариев
  - Профиль-клики (если доступно через Threads API)
  - Репосты / цитаты
- [ ] Данные подтягиваются автоматически через Threads API
- [ ] Если API не даёт метрику → поле для ручного ввода с подсказкой

---

### US-004.2 — Отметка "Привёл ли пост диалог?"

**Как** пользователь,  
**я хочу** отмечать, привёл ли пост к реальному диалогу или заявке,  
**чтобы** видеть связь: пост → действие → реакция.

**Acceptance Criteria:**
- [ ] Для каждого поста — переключатель: "Привёл диалог? Да / Нет"
- [ ] Если "Да":
  - Сколько диалогов (число)
  - Привёл ли к заявке (Да / Нет)
  - Опционально: связь с лидом из Lead Tracker
- [ ] Метка отображается в списке постов: 💬 / ❌

---

### US-004.3 — Дашборд аналитики за период

**Как** пользователь,  
**я хочу** видеть сводную аналитику за неделю / месяц,  
**чтобы** отслеживать общий прогресс.

**Acceptance Criteria:**
- [ ] Переключатель периода: 7 дней / 30 дней / всё время
- [ ] Метрики:
  - Постов опубликовано
  - Рост подписчиков (график)
  - Всего комментариев
  - Постов, приведших к диалогу
  - Конверсия: пост → диалог (%)
- [ ] Простые графики / индикаторы (не нужен сложный BI)

---

### US-004.4 — Лучший пост за период

**Как** пользователь,  
**я хочу** видеть свой лучший пост по engagement за период,  
**чтобы** понимать, какой контент делать больше.

**Acceptance Criteria:**
- [ ] Блок "Лучший пост" на дашборде аналитики
- [ ] Критерий: комментарии + диалоги (не лайки)
- [ ] Показывает: текст поста, угол, метрики
- [ ] Подсказка: "Попробуй написать ещё один пост в этом стиле"

---

### US-004.5 — Связь аналитики с углами контента

**Как** пользователь,  
**я хочу** видеть, какие углы контента (pain/case/belief/objection) работают лучше,  
**чтобы** оптимизировать контент-стратегию.

**Acceptance Criteria:**
- [ ] Разбивка метрик по углам:
  - Pain: среднее кол-во комментариев, диалогов
  - Case: среднее кол-во комментариев, диалогов
  - Belief: среднее кол-во комментариев, диалогов
  - Objection: среднее кол-во комментариев, диалогов
- [ ] Визуализация: какой угол лучше конвертирует в диалоги
- [ ] Влияет на рекомендацию угла в Content Draft Engine (US-003.6)
