# US-003: Content Draft Engine

## Описание модуля

Не "AI пишет посты". А система, которая:
- Предлагает **шаблоны углов** (pain / case / belief / objection)
- Генерирует черновики **на основе оффера** пользователя
- Даёт **редактируемые черновики**, заточенные под формат Threads

Решает боль: _"Не знаю, о чём писать"_ и _"Сижу перед пустым экраном"_.

---

## User Stories

### US-003.1 — Библиотека шаблонов углов

**Как** пользователь,  
**я хочу** видеть библиотеку шаблонов контента, сгруппированных по углам,  
**чтобы** выбрать подход для сегодняшнего поста.

**Acceptance Criteria:**
- [ ] 4 категории углов:
  - 🔴 **Pain** — пост о боли целевой аудитории
  - 🟢 **Case** — история успеха / кейс
  - 🔵 **Belief** — формирование убеждения
  - 🟡 **Objection** — снятие возражения
- [ ] В каждой категории — 3–5 шаблонов с примерами
- [ ] Шаблоны адаптированы под формат Threads (короткий текст, до 500 символов)
- [ ] Кнопка "Сгенерировать черновик" по каждому шаблону

---

### US-003.2 — Генерация черновика на основе оффера

**Как** пользователь,  
**я хочу** получить черновик поста, персонализированный под мой оффер и нишу,  
**чтобы** мне оставалось только отредактировать и опубликовать в Threads.

**Acceptance Criteria:**
- [ ] Генерация учитывает: нишу, оффер, ЦА, CTA из onboarding
- [ ] Черновик соответствует выбранному углу (pain / case / belief / objection)
- [ ] Длина оптимизирована для Threads (до 500 символов)
- [ ] Включён CTA в конце поста (в соответствии с настройкой пользователя)
- [ ] Тон и стиль соответствуют нише пользователя

---

### US-003.3 — Редактирование черновика

**Как** пользователь,  
**я хочу** редактировать сгенерированный черновик прямо в интерфейсе,  
**чтобы** добавить свой голос и детали перед публикацией.

**Acceptance Criteria:**
- [ ] Текстовый редактор с черновиком
- [ ] Счётчик символов (лимит Threads)
- [ ] Подсветка, если текст превышает лимит
- [ ] Автосохранение при редактировании
- [ ] Возможность вернуться к оригинальному черновику

---

### US-003.4 — Копирование и публикация

**Как** пользователь,  
**я хочу** скопировать готовый черновик одним кликом,  
**чтобы** быстро вставить его в Threads.

**Acceptance Criteria:**
- [ ] Кнопка "📋 Скопировать текст"
- [ ] Уведомление "Скопировано!"
- [ ] После копирования — предложение отметить "✅ Опубликовано"
- [ ] Опционально: кнопка "Открыть Threads" (deep link)

---

### US-003.5 — История черновиков

**Как** пользователь,  
**я хочу** видеть историю всех сгенерированных черновиков,  
**чтобы** вернуться к неиспользованным идеям.

**Acceptance Criteria:**
- [ ] Список всех черновиков с датой и углом
- [ ] Статусы: draft / published / skipped
- [ ] Возможность использовать старый черновик как новый пост
- [ ] Фильтрация по углу и статусу

---

### US-003.6 — Рекомендация угла на сегодня

**Как** пользователь,  
**я хочу** чтобы система рекомендовала угол для сегодняшнего поста,  
**чтобы** контент был разнообразным и не повторялся.

**Acceptance Criteria:**
- [ ] Система отслеживает, какие углы уже использовались
- [ ] Рекомендация основана на ротации: pain → case → belief → objection
- [ ] Учитывается эффективность (если case-посты дают больше engagement → чаще)
- [ ] Рекомендация отображается как подсказка, не принудительно
