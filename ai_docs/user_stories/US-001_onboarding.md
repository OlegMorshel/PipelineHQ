# US-001: Smart Onboarding (Стратегия за 15 минут)

## Описание модуля

Пользователь подключает свой профиль Threads, система анализирует его контент
и **автоматически заполняет** ключевые поля стратегии. Пользователь проверяет,
корректирует и подтверждает — получая готовую стратегию.

## Концепция: "Smart Onboarding"

Вместо пустых полей пользователь видит **предзаполненные данные** на основе:
- Его постов и публикаций в Threads
- Описания профиля (bio)
- Тематики контента
- Ссылок и CTA в постах

Это снижает трение и показывает ценность продукта **с первой минуты**.

### Флоу онбординга

```
Регистрация → Подключи Threads → Анализ контента → Предзаполненные поля → Проверь и поправь → Стратегия → Dashboard
```

## User Stories

### US-001.1 — Подключение профиля Threads

**Как** новый пользователь,  
**я хочу** подключить свой профиль Threads,  
**чтобы** система проанализировала мой контент и заполнила стратегию за меня.

**Acceptance Criteria:**
- [ ] Экран с предложением подключить Threads
- [ ] Авторизация через Threads API (Meta OAuth)
- [ ] Система забирает: bio, последние 20–50 постов, ссылки
- [ ] Индикатор загрузки: "Анализируем ваш контент в Threads..."
- [ ] Fallback: если подключение не удалось → возможность ручного ввода
- [ ] Кнопка "Пропустить — заполню вручную"

---

### US-001.2 — Автозаполнение ниши

**Как** новый пользователь,  
**я хочу** увидеть автоматически определённую нишу на основе моего контента в Threads,  
**чтобы** мне не нужно было думать, как это сформулировать.

**Acceptance Criteria:**
- [ ] Поле "Ниша" предзаполнено на основе анализа постов из Threads
- [ ] Рядом — пояснение: "🤖 Определено на основе ваших постов в Threads"
- [ ] Поле редактируемое — пользователь может изменить
- [ ] Если анализ не смог определить → поле пустое с плейсхолдером и примерами
- [ ] Примеры ниш для вдохновения (маркетинг, фитнес, финансы, дизайн)

---

### US-001.3 — Автозаполнение оффера и среднего чека

**Как** новый пользователь,  
**я хочу** увидеть предложенный оффер на основе моего контента в Threads,  
**чтобы** быстро скорректировать и двигаться дальше.

**Acceptance Criteria:**
- [ ] Поле "Оффер" предзаполнено (из bio, закреплённых постов, ссылок)
- [ ] Поле "Средний чек" предзаполнено, если найдены упоминания цен
- [ ] Оба поля редактируемые
- [ ] Если не найдено → пустое поле + подсказки-примеры офферов
- [ ] Средний чек: числовое поле с выбором валюты

---

### US-001.4 — Автозаполнение целевого клиента

**Как** новый пользователь,  
**я хочу** увидеть описание моего целевого клиента, составленное на основе моих постов в Threads,  
**чтобы** проверить, правильно ли система поняла мою аудиторию.

**Acceptance Criteria:**
- [ ] Поле "Целевой клиент" предзаполнено (анализ тем, обращений, кейсов в постах)
- [ ] Формат: 1–2 предложения (например: "Предприниматели в сфере EdTech, которые хотят масштабировать продажи через контент")
- [ ] Поле редактируемое
- [ ] Если не найдено → пустое + подсказки (должность, боль, где обитает)

---

### US-001.5 — Автовыбор CTA (целевого действия)

**Как** новый пользователь,  
**я хочу** чтобы система предложила CTA на основе того, как я сейчас закрываю клиентов в Threads,  
**чтобы** план действий был реалистичным.

**Acceptance Criteria:**
- [ ] CTA предвыбран на основе анализа (если "напишите в DM" → dm, если есть Calendly → call, если ссылки → link)
- [ ] Варианты: "Написать в DM", "Запись на созвон", "Переход по ссылке", "Своё"
- [ ] Можно изменить выбор
- [ ] Если не определено → ничего не выбрано, пользователь выбирает сам

---

### US-001.6 — Экран подтверждения и редактирования

**Как** пользователь,  
**я хочу** увидеть все предзаполненные поля на одном экране,  
**чтобы** проверить всё разом, скорректировать и подтвердить.

**Acceptance Criteria:**
- [ ] Summary-экран со всеми полями (ниша, оффер, чек, клиент, CTA)
- [ ] Каждое поле — inline-редактируемое (клик → редактирование)
- [ ] Визуальная метка: 🤖 "Заполнено автоматически" / ✏️ "Изменено вами"
- [ ] Кнопка "Подтвердить и получить стратегию"
- [ ] Валидация: все обязательные поля заполнены

---

### US-001.7 — Генерация стратегии

**Как** пользователь, подтвердивший данные,  
**я хочу** увидеть сгенерированную стратегию,  
**чтобы** понимать свой план действий в Threads.

**Acceptance Criteria:**
- [ ] Экран с резюме стратегии на основе подтверждённых данных
- [ ] Стратегия включает:
  - Позиционирование в Threads
  - Рекомендуемые типы контента (углы)
  - CTA-формулировка
  - Рекомендуемая частота публикаций
- [ ] Кнопка "Начать" → переход к Daily Growth Plan
- [ ] Стратегия сохраняется и доступна в профиле

---

### US-001.8 — Сохранение прогресса онбординга

**Как** пользователь,  
**я хочу** чтобы мой прогресс сохранялся, если я закрою вкладку,  
**чтобы** продолжить с того места, где остановился.

**Acceptance Criteria:**
- [ ] Прогресс сохраняется при переходе между шагами
- [ ] При повторном входе — возврат к последнему незавершённому шагу
- [ ] Данные синхронизируются с сервером
