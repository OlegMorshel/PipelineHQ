# US-005: Lead Tracker Lite

## Описание модуля

Простая таблица для трекинга лидов, которые пришли из контента в Threads.
Контент перестаёт быть абстракцией — **видна связь с деньгами**.

Не CRM. Не Salesforce. Простой трекер: откуда пришёл → какой статус → результат.

---

## User Stories

### US-005.1 — Добавление лида

**Как** пользователь,  
**я хочу** быстро добавить нового лида,  
**чтобы** не терять контакты, пришедшие из Threads.

**Acceptance Criteria:**
- [ ] Кнопка "+ Добавить лид" на странице Lead Tracker
- [ ] Поля:
  - **Имя / Username** (обязательно)
  - **Откуда пришёл** (комментарий / DM / ответ на пост)
  - **Какой пост** (выбор из списка опубликованных постов)
  - **Заметка** (свободный текст)
- [ ] Быстрое добавление — минимум полей, максимум скорости
- [ ] Также можно добавить лид из Daily Growth Plan (US-002.4) при отметке "Заявка"

---

### US-005.2 — Просмотр списка лидов

**Как** пользователь,  
**я хочу** видеть всех своих лидов в одном месте,  
**чтобы** понимать состояние своей воронки.

**Acceptance Criteria:**
- [ ] Таблица с колонками:
  - Имя / Username
  - Откуда (источник)
  - Пост (связанный пост)
  - Статус
  - Дата добавления
  - Заметка
- [ ] Сортировка по дате / статусу
- [ ] Фильтрация по статусу
- [ ] Поиск по имени

---

### US-005.3 — Изменение статуса лида

**Как** пользователь,  
**я хочу** менять статус лида по мере продвижения по воронке,  
**чтобы** отслеживать прогресс от первого контакта до сделки.

**Acceptance Criteria:**
- [ ] Статусы (Kanban или dropdown):
  - 🆕 **new** — новый контакт
  - 💬 **talking** — в диалоге
  - 📞 **call** — назначен/состоялся созвон
  - ✅ **won** — сделка закрыта, клиент оплатил
  - ❌ **lost** — сделка не состоялась
- [ ] Изменение статуса одним кликом / drag-and-drop
- [ ] При переходе в "won" — опциональное поле "Сумма сделки"
- [ ] При переходе в "lost" — опциональное поле "Причина"

---

### US-005.4 — Связь лида с постом

**Как** пользователь,  
**я хочу** видеть, какой пост привёл конкретного лида,  
**чтобы** понимать, какой контент реально генерирует бизнес.

**Acceptance Criteria:**
- [ ] При создании лида — выбор поста из списка
- [ ] В карточке лида — ссылка на пост
- [ ] В аналитике поста (US-004) — количество лидов от этого поста
- [ ] Обратная связь: пост → лиды → сделки

---

### US-005.5 — Сводка по воронке

**Как** пользователь,  
**я хочу** видеть сводку по всей воронке,  
**чтобы** понимать, сколько лидов на каждом этапе и какой у меня conversion rate.

**Acceptance Criteria:**
- [ ] Мини-дашборд над таблицей:
  - Всего лидов
  - По статусам: new / talking / call / won / lost
  - Конверсия: лиды → won (%)
  - Общая сумма сделок (won)
- [ ] Период: за всё время / за 30 дней
- [ ] Обновляется в реальном времени

---

### US-005.6 — Заметки по лиду

**Как** пользователь,  
**я хочу** добавлять заметки к лиду после каждого взаимодействия,  
**чтобы** не забывать контекст разговора.

**Acceptance Criteria:**
- [ ] Поле заметок в карточке лида
- [ ] Возможность добавлять несколько заметок (лог)
- [ ] Дата и время каждой заметки
- [ ] Последняя заметка видна в списке лидов (preview)
